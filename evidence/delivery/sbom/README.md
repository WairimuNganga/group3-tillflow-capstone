# SBOM + image scan report — golden-path base image

**DRI: Wairimu**

`ci.yml`'s `docker-golden-path` job generates and uploads both of these on every PR/push, but CI
artifacts expire after 30 days. These are a permanent, point-in-time copy for evidence.

- [`golden-path-sbom.cyclonedx.json`](golden-path-sbom.cyclonedx.json) — CycloneDX SBOM, 3,498
  components, generated by [`anchore/sbom-action`](../../../.github/workflows/ci.yml).
- [`golden-path-trivy-report.txt`](golden-path-trivy-report.txt) — Trivy scan
  (`--severity HIGH,CRITICAL --ignore-unfixed`), the same fail-on-fixable policy the CI gate
  enforces. Clean at the commit these were generated from — no HIGH/CRITICAL findings with a fix
  available, OS or Python packages.

Captured from `tillflow-golden-path:ci` built at commit
[`92ea6aa`](https://github.com/WairimuNganga/group3-tillflow-capstone/commit/92ea6aadb77b0234378149bf620097b69fb857e4)
(`services/_shared/Dockerfile.base`, after the `apt-get upgrade` fix for the real fixable HIGH
finding it originally caught — see that commit's history for the before/after).

Reproduce:

```bash
cd services/_shared
docker build -f Dockerfile.base --build-arg SERVICE_NAME=base \
  --build-arg GIT_COMMIT_SHA=$(git rev-parse --short HEAD) -t tillflow-base:local .
docker build -f examples/Dockerfile \
  --build-arg GIT_COMMIT_SHA=$(git rev-parse --short HEAD) -t tillflow-golden-path:local .

syft tillflow-golden-path:local -o cyclonedx-json=sbom.cyclonedx.json
trivy image --severity HIGH,CRITICAL --ignore-unfixed --format table tillflow-golden-path:local
```
